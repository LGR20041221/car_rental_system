# 基于 Django 的汽车租赁智能管理系统

面向中小型汽车租赁企业的 B2C 租赁管理平台，采用 Django 前后端不分离（MVT）架构，融合**动态定价**与**运营数据可视化**两大智能特色模块，实现从选车、下单、支付到还车结算的完整业务闭环。

## 一、功能模块

| 模块 | 说明 |
|------|------|
| 用户管理 | 注册（邮箱验证码）、登录、密码找回、个人信息、修改密码、管理端用户管理 |
| 车辆管理 | 车辆列表筛选、详情查看、管理端增删改查、图片管理、品牌/分类维护 |
| 租赁订单 | 下单（租期冲突校验）、模拟支付、取消、续租审批、确认还车、管理端审核/强制还车 |
| 支付与费用 | 动态租金计算、押金管理、违约金、优惠券领取/使用、账单、退款处理、财务报表 |
| 评价模块 | 已完成订单 1-5 星评价、车辆详情查看评价、管理端隐藏不当评价、评分统计 |
| 收藏模块 | 一键收藏/取消、我的收藏（筛选/批量取消）、管理端收藏排行与偏好分析 |
| 推荐模块 | 车辆详情同品牌相似推荐（最多 5 辆）、首页销量 TOP10 热门推荐 |
| 动态定价 ⭐ | 节假日/周末上浮、旺季/淡季调价、早鸟/长租优惠，价格预览逐日明细 |
| 数据可视化 ⭐ | 数据大屏：订单趋势、收入构成、热门车型、车辆利用率、用户增长 |
| 消息通知 | 订单状态通知、消息中心（已读/未读）、系统公告（模糊搜索/详情/置顶） |
| 后台管理 | 侧边导航栏管理端：仪表盘、用户/车辆/订单、营销/运营/财务管理、系统设置 |

## 二、技术栈

- **后端框架**：Django 4.2.x（函数视图 FBV，业务逻辑下沉 services 层）
- **前端**：Bootstrap 5.3 + jQuery 3.7（本地静态资源，离线可用）
- **可视化**：ECharts 5.5
- **数据库**：MySQL 8.0（库名 `car_rental_system`，ORM 迁移管理）
- **认证**：Django Session + 自定义 `@login_required` / `@admin_required` 装饰器
- **密码存储**：bcrypt（BCryptSHA256PasswordHasher）
- **验证码**：6 位随机数字，Django 缓存存储（开发用 LocMemCache，生产可切换 Redis）

## 四、快速开始

### 1. 安装依赖

```bash
pip install -r requirements.txt
# 或指定安装：Django>=4.2,<5.0 mysqlclient bcrypt Pillow
```

### 2. 准备数据库

在 MySQL 中创建数据库（字符集 utf8mb4）：

```sql
CREATE DATABASE car_rental_system DEFAULT CHARACTER SET utf8mb4 COLLATE utf8mb4_general_ci;
```

修改 `car_rental_system/settings.py` 中的数据库连接信息：

```python
DATABASES = {
    'default': {
        'ENGINE': 'django.db.backends.mysql',
        'NAME': 'car_rental_system',
        'USER': 'root',
        'PASSWORD': '你的密码',
        'HOST': '127.0.0.1',
        'PORT': '3306',
        'OPTIONS': {'charset': 'utf8mb4'},
    }
}
```

### 3. 迁移数据库

```bash
python manage.py makemigrations
python manage.py migrate
```

### 4. 一键生成测试数据

```bash
python manage.py generate_test_data
```

生成内容：管理员 1 名、普通用户 49 名、品牌 8 个、车辆 30 辆、图片 90 张、订单 100 单、评价 40 条、优惠券 10 张、通知 60 条、公告 10 条、收藏 80 条，并初始化定价规则与系统参数。

> 重新生成（先清空旧数据）：`python manage.py generate_test_data --flush`

### 5. 启动服务

```bash
python manage.py runserver
```

访问 http://127.0.0.1:8000/ 即可。

## 六、演示流程（答辩推荐）

1. **注册**：填写用户名 + 手机号 + 邮箱，点击「发送验证码」（终端输出 6 位验证码），输入后注册成功
2. **登录**：用户账号登录，浏览首页热门推荐（销量 TOP10）
3. **选车**：车辆列表筛选（分类/品牌/价格/燃油），进入详情查看图片、参数、评价、相似推荐与近 30 天占用日期
4. **收藏**：详情页/列表页一键收藏，我的收藏支持批量取消
5. **下单**：选择取还车日期与地点，页面实时展示「原价 → 动态调价 → 优惠券 → 应付租金 + 押金」价格明细；租期冲突时提示最近可预约时间段
6. **支付**：模拟支付租金 + 押金，订单进入「已支付」
7. **还车**：用户确认还车 → 管理员核验 → 订单完成、押金自动退还（账单可见）
8. **评价**：已完成订单提交 1-5 星评价
9. **管理端**：admin 登录后查看数据大屏（订单趋势/收入构成/热门车型/车辆利用率/用户增长）、处理订单审核/续租审批/退款、配置定价规则与优惠券

## 七、动态定价说明

租金按**价格计算链**逐日计算：基础日租金 → 动态定价（逐日系数）→ 优惠券抵扣 → 应付租金，押金单列。

| 规则 | 触发条件 | 默认幅度 |
|------|----------|----------|
| 节假日上浮 | 法定节假日 | +30% |
| 周末上浮 | 周六/周日 | +20% |
| 旺季调价 | 预订率 > 80% | +20% |
| 淡季促销 | 预订率 < 30% | -15% |
| 早鸟优惠 | 提前 ≥ 7 天 | -10% |
| 长租优惠 | 连续 ≥ 7 天 | -15% |

定价规则与押金/违约金倍数可在管理端「定价规则 / 系统设置」中配置。

## 九、配置说明

- **验证码发送**：开发阶段使用 `console` 邮件后端（验证码打印在终端），生产环境可在 `settings.py` 切换 SMTP 邮箱服务
- **缓存**：默认本地内存缓存（零依赖），生产可切换 Redis（`settings.py` 中已注释示例）
- **数据大屏**：进入管理端「数据大屏」或 `/admin/dashboard/` 查看
- **测试**：`python test_smoke.py` 可运行全流程冒烟测试（覆盖注册→登录→选车→下单→支付→还车→评价→管理端操作）

## 十、常见问题

| 问题 | 解决 |
|------|------|
| 注册时验证码没收到 | 查看运行 `runserver` 的终端输出，开发阶段验证码打印在控制台 |
| MySQL 连接报错 | 确认 MySQL 服务已启动、`car_rental_system` 库已创建、`settings.py` 密码正确 |
| 中文字符乱码 | 数据库需使用 `utf8mb4` 字符集 |
| 页面样式异常 | 确认 `static/lib/` 下存在 bootstrap/jquery/echarts 本地文件（已内置） |
